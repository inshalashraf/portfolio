# Inshal Ashraf — Portfolio

Personal portfolio website for **Md. Inshal Ashraf**, a B.Tech Computer Science and Data Science student.

The site presents my technical skills, current focus, and ways to connect. It is built as a React application and is prepared for static deployment through GitHub Pages.

## Highlights

- Responsive personal portfolio
- Animated role introduction and interactive terminal
- Skills, projects, experience, and contact sections
- Keyboard-accessible navigation and focus states
- Search/social metadata and sitemap/robots files
- GitHub Pages deployment workflow

## Tech Stack

- React
- JavaScript
- CSS
- GitHub Actions and GitHub Pages

## Run Locally

Requirements: Node.js and npm.

```bash
npm install
npm start
```

The development server runs at `http://localhost:3000` by default.

## Production Build

```bash
CI=false npm run build
```

The generated production files are placed in the `build/` directory. The CI flag prevents warnings from being treated as build failures in this project’s deployment workflow.

## Deployment Verification

After pushing to the default branch:

1. Open the repository's **Actions** tab.
2. Confirm the Pages deployment workflow completes successfully.
3. Open the live site and hard-refresh if an older cached version appears.
4. Check the repository's **Settings → Pages** if the deployment URL is unavailable.

Live site: https://inshalashraf.github.io/portfolio/
