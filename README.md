# Inshal Ashraf — Portfolio

Personal portfolio website for **Md. Inshal Ashraf**, a B.Tech Computer Science and Data Science student.

The site presents my technical skills, current focus, and ways to connect. It is built as a React application and is prepared for static deployment through GitHub Pages.

## ✨ Highlights

- Responsive personal portfolio
- Animated role introduction
- Skills carousel
- GitHub, LinkedIn and Instagram links
- Smooth navigation between sections
- Contact section
- Accessible labels and improved image alt text
- GitHub Pages deployment configuration

## 🚀 Run Locally

Requirements: Node.js and npm.

```bash
npm install
npm start
```

The development server runs at `http://localhost:3000` by default.

## 📦 Production Build

```bash
npm run build
```

The generated production files are placed in the `build/` directory.

## 🌐 Deployment

The project already contains the `homepage`, `predeploy`, and `deploy` configuration needed for GitHub Pages.

```bash
npm run deploy
```

The configured site address is:

`https://inshalashraf.github.io/portfolio/`

Deployment status should be verified from the GitHub repository's Pages/Actions settings after a deployment run.
